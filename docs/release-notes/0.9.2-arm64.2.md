# Host Cassettes 0.9.2-arm64.2

## 変更点

- アップデートの署名が不適切で認証できないエラーを修正
  - appcast に旧リポジトリの Gas Mask エントリが混在し、ビルド番号 `4`（0.8.9）が Host Cassettes の番号を上回るため Sparkle が誤った更新を適用しようとしていた問題を修正
  - `CFBundleVersion` を `5` に修正（ビルド番号が逆行していた問題を解消）
  - appcast から旧エントリを除去済み

## 動作環境

- macOS 13 Ventura 以降
- Apple Silicon Mac

## インストール

zip を展開して `Host Cassettes.app` をアプリケーションフォルダに移動してください。
