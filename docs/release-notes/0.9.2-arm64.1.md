# Host Cassettes 0.9.2-arm64.1

## 変更点

- 外部からの hosts 変更検知時の動作を設定で切り替え可能に（デフォルト: 自動復帰オフ）
  - オフの場合、外部変更を検知するとステータスバーアイコンが警告表示（黄色 !）に切り替わり動作を一時停止
  - アイコンクリックで認証し、アクティブ hosts を再適用して監視を再開
  - メニューから別の hosts を手動選択した場合も一時停止を解除
- ステータスバーアイコンおよび編集画面のアイコンにカスタムカラーを設定可能に
  - アイコン選択ダイアログにカラーピッカーを追加

## 動作環境

- macOS 13 Ventura 以降
- Apple Silicon Mac

## インストール

zip を展開して `Host Cassettes.app` をアプリケーションフォルダに移動してください。
